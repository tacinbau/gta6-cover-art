# Vice City Cover Studio

Turn any photo and a caption into GTA-style multi-panel cover art, offline in your browser. Pick a layout (hero grid, comic strip, split duo, full bleed), a colour grade (sunset, neon, palm dusk, noir), crop and position each panel by dragging, edit the title and subtitle, and export a PNG in 1080×1080, 1080×1350 or 1920×1080.

Photos are read on your own machine and never uploaded. All art, lettering and grades are drawn by the app itself — no Rockstar Games logo, artwork or font is used.

Run it: `node serve.ts`, then open http://localhost:8080.
